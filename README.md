## 🔐 Spotlight: Crypsia

> **Crypsia** is my flagship project — a blockchain-powered supply chain security platform that brings **transparency, traceability, and trust** to product journeys from manufacturer to consumer.

```
📦 Raw Material → 🏭 Manufacturer → 🚚 Distributor → 🏪 Retailer → 🙋 Consumer
        |               |                |               |              |
        └───────────────┴────────────────┴───────────────┴──────────────┘
                            🔗 Every step recorded on-chain
```

**What makes Crypsia powerful:**
- 🛡️ **Immutable records** — tamper-proof product history on blockchain
- 🔍 **QR-based verification** — instant authenticity check at any stage
- 📊 **Real-time tracking** — live visibility across the supply chain
- 🚨 **Fraud detection** — automated alerts for counterfeit or diverted goods
